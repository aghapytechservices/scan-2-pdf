Scan 2 PDF for Outlook

Support

Help for the Scan 2 PDF Outlook add-in and the Scan 2 PDF Bridge app.

Getting started

  1. Install the Scan 2 PDF Bridge on your Windows PC: unzip, double-click Scan2PdfBridge.exe and choose Yes to install. It starts automatically every time you sign in.
  2. In Outlook, start a new email and click Scan to PDF on the ribbon (in new Outlook, under Apps).
  3. Choose your scanner and settings, click Scan, then Attach.

Common questions

The panel says "Scanner service not reachable"

  • Check that the Scan 2 PDF icon is in the system tray (click the ^ next to the clock). If not, run Scan2PdfBridge.exe again and choose Yes to install it.
  • To start it automatically at sign-in, right-click the tray icon and make sure Start with Windows is checked.
  • If Outlook or your browser asks to let the add-in connect to apps on this device, choose Allow.
  • Open http://127.0.0.1:52801/ on the same PC. You should see the bridge status page.

No scanner is listed

The bridge uses Windows' built-in scanner support (WIA). Make sure the scanner is on and appears in the Windows Scan app. Install the manufacturer's driver if it doesn't.

"Scanner error" when scanning

Try a different resolution or paper size. If it keeps failing, right-click the tray icon → Open log folder and include bridge.log when you contact us.

Does it work on Mac?

The scanner bridge is Windows-only. On other platforms you can still use Add images from file to turn JPG/PNG images into a PDF attachment.

The attachment is too large

Use 150 dpi, grayscale, or a lower JPEG quality (under Advanced).
